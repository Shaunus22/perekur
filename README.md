# 👹 Перекур

Chrome-расширение для офисного перекура: призыв голосованием «идти / не идти» и мгновенный шрек в окне поверх работы.

Расширение не хранит картинки — все gif/webp лежат на сервере, поэтому набор можно менять **без обновления расширения**.

## Как это работает

| Фича | Что происходит |
|---|---|
| **Перекур** | Нажали кнопку — коллеги получают системное уведомление с двумя кнопками и 2 минуты на ответ. Когда все проголосовали (или вышел таймаут) — приходят итоги. |
| **Шрек** | Нажали иконку шрека в заголовке попапа — у всех коллег поверх окон появляется окно 420×420 с анимированной картинкой, через 12 секунд само закрывается. |
| **Честная очередь** | Шреки не теряются: сервер держит их 5 минут, каждый клиент отмечает, что уже показывал. Кликнёли 3 раза подряд — все 3 дойдут. |
| **Авто-отмена** | Если в опросе кроме вас никого нет — голосование сразу отменяется с объяснением, а не висит 2 минуты. |
| **HTTPS** | Трафик идёт через Caddy + Let's Encrypt, в корпоративной сети админы не видят содержимого. |

## Установка расширения

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика** (тумблер сверху справа)
3. **Загрузить распакованное расширение** → выберите папку с этим репозиторием
4. Кликните по иконке расширения → «Настройки» и впишите адрес сервера, например `perekur.example.duckdns.org`
5. Задайте своё имя — его увидят коллеги

> В настройках можно вписать и `IP-адрес` (тогда будет `http://IP:3000`), и `домен` (тогда `https://домен`, как надо).

## Обновление

Расширение само проверяет `version.txt` в этом репозитории и показывает в попапе подсказку, если вышла новая версия. Чтобы обновиться: `chrome://extensions` → «Обновить» на карточке расширения.

## Запуск своего сервера

Сервер — это `server.js` (Node.js, **без единой внешней зависимости**), картинки кладутся рядом в папку `prikol/`.

```bash
node server.js          # слушает 0.0.0.0:3000
```

Полезно знать:

- `GET /status` — сколько клиентов онлайн, есть ли активный опрос
- `POST /shrek-image` — отдаёт случайную картинку шрека
- `POST /client-log` — сюда расширения пишут, что реально показали (удобно для отладки)

Папки и переменные окружения:

| Что | Значение |
|---|---|
| Порт | `PORT=3000` по умолчанию, можно поменять через `PORT=8080 node server.js` |
| Картинки | `prikol/` рядом с `server.js` |
| Сжатые webp | `prikol-webp/` (создаётся скриптом `convert-gifs.sh`) |

### Сжатие гифок

Большие gif (>1 МБ) конвертируются в анимированный webp — файл становится в 10–15 раз легче, анимация сохраняется:

```bash
./convert-gifs.sh       # требуется ffmpeg
```

### HTTPS

Положите свой домен в `deploy/Caddyfile` (по умолчанию там плейсхолдер) и запустите Caddy — сертификат Let's Encrypt выпустится сам. Затем включите `deploy/perekur.service`, чтобы сервер поднимался при загрузке.

### Загрузка картинок

Картинки лежат **вне репозитория** (в `.gitignore` — строка `prikol/`), чтобы набор менялся без правки кода. Скрипт загрузки лежит рядом с папкой картинок на вашем компьютере и сам чистит старые файлы, заливает новые и запускает сжатие.

## Структура

```
manifest.json      манифест расширения (MV3)
background.js      вся логика: опросы, шреки, уведомления, таймеры
popup.html/.js     попап: кнопка перекура, иконка шрека, настройки
shrek.html/.js     окно показа шрека
config.js          нормализация адреса сервера, репозиторий для проверки версий
server.js          сервер: опросы, очередь шреков, раздача картинок
convert-gifs.sh    конвертация больших gif в webp
version.txt        версия для проверки обновлений
deploy/            образцы Caddyfile и systemd-юнита
```

## Ограничения

- `chrome.alarms` в MV3 не позволяет проверять чаще раза в 30 секунд, поэтому опрос идёт циклами по 30 секунд.
- WebSocket в service worker не держится (Chrome выгружает его примерно через 30 секунд), поэтому используется опрос по HTTP.
- `alwaysOnTop` для окон недоступен в некоторых версиях Chrome — если не поддерживается, окно шрека всё равно открывается, но просто не поверх всех (код сам это определяет и откатывается).
- Шрек показывается отдельным окном, а не системным уведомлением: Chrome не анимирует gif в уведомлениях — показывает только первый кадр.
